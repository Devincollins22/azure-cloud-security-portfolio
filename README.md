# Azure Cloud Security Portfolio

Hands-on Azure security labs built while preparing for **Microsoft SC-500 (Cloud and AI Security Engineer Associate)** — one lab per exam domain.

| Domain | Lab |
|---|---|
| 1 – Identity, access & governance | [Key Vault, Azure Policy, resource locks](domain-1-identity-governance) |
| 2 – Storage, databases & networking | [Segmented network + private storage](domain-2-storage-networking) |
| 3 – Compute & AI | [Hardened VM + AI guardrails](domain-3-compute-ai) |
| 4 – Security posture & monitoring | [Defender for Cloud](domain-4-posture-monitoring) |

See [ROADMAP.md](ROADMAP.md) for the study plan. Every change is checked by a GitHub Actions pipeline (Terraform fmt/validate + Checkov).
